Network & Exfiltration Testing

Egress Probe

Tests DNS, HTTP/S, IMDS, and common port egress from the current environment. Validates SC-7 boundary controls.

Tests: DNS resolution, HTTP/HTTPS egress, IMDS v1/v2, ports 53/80/443/8080/8443

Lateral Movement

Discovers adjacent hosts on the local subnet and probes common service ports. Run from inside the target container.

Requires: nmap (falls back to ping sweep)

Callback Listener

The callback listener runs as a standalone process on your infrastructure outside the test VPC. Start it from the command line:

python3 ai-test-harness/network/callback-infra/listener.py --port 8888

All incoming requests are logged to callbacks.jsonl with timestamps for correlation against the evidence timeline.

VPC Network Mapper

Queries AWS for security groups, NACLs, and VPC flow logs. Requires AWS CLI configured with the test profile. Run from the command line with environment variables set:

export SG_IDS=sg-xxx,sg-yyy export SUBNET_ID=subnet-xxx export VPC_ID=vpc-xxx bash ai-test-harness/network/egress-tests/vpc_mapper.sh
